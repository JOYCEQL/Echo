# Echo 使用与备份指南

[返回首页](../README.md)

## 整理笔记

点击左侧空间列表下方的「+」新建空间，例如「工作」或「周末计划」。同一空间里可以同时放结构化文档和自由画布。右键页面可以新建子页面，拖动页面可以重新排序或移入其他空间。误删的页面可以在设置的回收站中恢复。要按标题或正文查找笔记，点击页面列表上方的搜索按钮。

## 编辑文档和画布

| 想做什么 | 如何操作 |
| --- | --- |
| 插入内容 | 在正文行首或空格后输入 `/`，用中文、英文或拼音缩写筛选。用方向键选中命令，按 Enter 插入。 |
| 写结构化段落 | 在行首输入 `#`、`-` 或 `- [ ]`，再按空格，分别生成标题、列表或待办。选中文字可打开格式工具栏。 |
| 浏览长文 | 文档有标题后，点击右上角的大纲按钮，选择章节跳转。点击大纲标题旁的箭头收起。 |
| 排版图片 | 单击正文里的图片，拖动角点等比缩放，用对齐控件选择左、中、右。 |
| 编辑表格 | 输入 `/表格` 插入表格。Tab 切换单元格，在末格按 Tab 增加一行。拖动列分界线调宽，右键管理行列。 |
| 移动画布卡片 | 拖动卡片顶部把手，拖动右边缘改变宽度。需要整体整理时，从画布菜单选择「一键铺平」，可一次撤销。 |
| 写图表和公式 | 用 `/mermaid` 或 `/math` 插入源码块，在源码和预览间切换。正文里的行内公式可写成 `$E=mc^2$`。 |

## 导入、导出与备份

**导入 Markdown。** 先选中目标空间，点击「新建页面」旁边的文件夹图标选择 Markdown 文件，也可以直接把文件拖入窗口。导入含本地图片的笔记时，请保持原文件与图片之间的相对路径有效。

**分享单篇笔记。** 从页面菜单导出 Markdown。如果导出结果带有同名的 `.assets` 图片目录，请将它与 Markdown 文件一起发送。

**备份或搬到另一台电脑。** 在 Echo 的设置中打开本地数据目录，然后退出应用。复制整个目录，包括隐藏的 `.echo`。在新电脑上先退出 Echo，再将备份放到对应的位置；如果目标位置已有笔记，先另存一份。

| 系统 | 默认数据目录 |
| --- | --- |
| macOS | `~/Library/Application Support/Echo/` |
| Windows | `%LOCALAPPDATA%\Echo\` |

`Documents/` 保存文档，`Canvas/` 保存画布正文和同名的 `.canvas.json` 布局文件。`images/` 保存图片，`.echo/` 保存笔记索引和设置。单独复制画布的 Markdown 只会带走正文；若要还原卡片位置和尺寸，需要一并保留布局文件。

## 从旧版 SQLite 笔记库迁移

如果使用过以 SQLite 保存笔记的早期 macOS 版本，先退出 Echo 并备份整个数据目录。在源码仓库根目录构建迁移工具需要的 Echo 程序，再预演迁移：

```sh
cargo build --release --locked
python3 scripts/migrate_sqlite.py --root "$HOME/Library/Application Support/Echo" --binary target/release/echo
```

预演会在隔离副本中逐篇验证。确认结果后，在同一条 Python 命令末尾加上 `--apply` 才会写入新库。原始数据库与图片会保留在备份中。[迁移脚本](../scripts/migrate_sqlite.py)
