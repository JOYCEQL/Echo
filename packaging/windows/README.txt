Echo for Windows x64

Requires Windows 10 1809 / Windows 11 and a DirectX 12 or Vulkan capable GPU driver.
Window background transparency requires DirectX 12.
Run Echo.exe; the portable zip must be extracted first.
Notes: %LOCALAPPDATA%\Echo
Use Ctrl instead of Command for shortcuts. Ctrl+, opens Settings.
The setup installs per-user, without administrator privileges.
Uninstalling the application preserves notes.
In-app updates require the setup edition and a build with a release repository/public key.
This preview is not Authenticode signed; Windows may show SmartScreen publisher warnings.
