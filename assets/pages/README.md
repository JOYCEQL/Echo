# 笔记类型图标

`document.png` 和 `canvas.png` 是用户选定的单色手绘方案的透明 PNG 素材，均为 128 × 128，界面使用 24 × 24 的固定图标位。内部纸面为不透明暖白，外部透明，因此可以放在浅色、深色及选中背景上。

使用内置 ImageGen 从 2026-11-20 选定的修正版分别提取生成，再裁掉外围透明留白并缩小。不使用运行时图片生成、网络请求或替代图标。应用启动时通过现有 Rune ImageCache 解码，所有笔记行共享同一组像素。

生成指令要点：

- 文档：独立折角纸张，暖炭灰手绘线条，三条短文字笔画，右下角少量浅灰排线，暖白纸面，透明背景。
- 自由画布：紧凑的两张轻微反向倾斜、部分重叠的纸卡，每张两条短笔画，少量浅灰排线；无连接弧线，视觉分量与文档图标一致，透明背景。
